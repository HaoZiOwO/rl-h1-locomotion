# IMU 步态相位估计 — Daphnet 数据集验证

- 数据: Daphnet Freezing of Gait (UCI), S01R01.txt 正常行走段
- 传感器: 踝部三轴加速度计 64Hz [mg→m/s²]
- 方法: 幅值 → Butterworth 带通 0.5-8Hz → 峰值检测(heel strike) → 周期/相位

## 结果

| 指标 | 数值 |
|---|---|
| 检出 heel strike | 40 |
| 步频 | 87.9 步/分 |
| 步态周期 | 682 ± 238 ms |
| 分析时长 | 750 s |

## 说明

- 帕金森患者数据步态变异性大于健康人，检测仍稳定 → 鲁棒性证据
- 支撑相/摆动相划分：周期前 60% 支撑相、后 40% 摆动相（外骨骼助力时机的决策基础）
