# SAC 教师蒸馏对照（阴性结果，兑现 README 所列后续工作）

> 状态：完成（2026-08-15）。README 曾写"SAC（6416）当教师的对照列为后续工作"——已兑现，结果为阴性，照发。

## 1. 结果总表

| 配置 | 示范采样 | 平均奖励 | 保持率 |
|---|---|---|---|
| **教师 SAC**（2M 步） | — | **6416.8 ± 711.8** | 100% |
| 受限 28 维学生（BC） | 随机 | 346.0 ± 37.5 | 5.4% |
| 受限 28 维学生（BC） | 确定性 | 324.1 ± 49.6 | 5.1% |
| 全 376 维学生（BC） | 随机 | 564.7 ± 339.4 | 8.8% |
| 对照：PPO 教师蒸馏（既有） | 随机 | 534.4 vs 508.3 | 105% |

> 统计口径注：全 376 维学生单局 std ±339 显著大于其余组（单局分数重尾/双峰），
> 8.8% 均值保持率应结合分布解读；成功率口径可从评估日志重算。

## 2. 变量分离（三个对照排除两个假设）

1. **不是观测削减**：全 376 维学生也只有 8.8%——28 维受限不是主因。
2. **不是示范噪声**：确定性示范（教师均值动作，即 SAC 评估时的 6416 策略）一样失败（5.1%）。
3. **机制假说：SAC 教师对 BC 蒸馏系统性失败**——它的高回报可能来自**高增益紧反馈**（6416 分是
   快跑，不是慢走）；BC 的残差误差（val MSE 0.026，训练
   本身没问题：均值动作基线 MSE 0.087）在数百步内累积 → 状态漂离教师分布 → 误差放大
   → 摔倒。本实验未直接测量策略增益/扰动敏感度（Jacobian 范数未测），且存在未控制的
   混淆：**SAC 教师网络 [256,256] vs 学生 [64,64]，而 PPO 教师与学生同为 [64,64]**——
   "SAC 免疫蒸馏"与"学生容量装不下教师"在当前对照下不可分。PPO 教师是慢走策略，
   稳定裕度可能吸收同样的误差。

## 3. 机制级结论

> "学生能继承的是**静态映射**的性能，继承不了**反馈策略**的性能（机制假说）。SAC 的
> 6416 分里有相当一部分价值在高增益闭环反馈里，BC 蒸馏把它压成开环静态映射，误差
> 一累积就没有校正回路了。PPO 教师本身就是低增益静态映射，所以蒸馏能持平（534 vs
> 508）。我用三个对照锁定了归因方向：全观测也救不回来、确定性示范也救不回来——
> 但有一个混淆我还没排除：SAC 教师和学生容量差一个数量级（[256,256] vs [64,64]），
> PPO 教师和学生同构。观测削减 92.6% 性能持平的结论只在 PPO 教师下成立，这是边界。"

## 4. 边界声明

- 示范预算 8247 条（10 局随机采样，含 2 局教师自身摔倒）——与既有 BC 预算同量级
- 学生架构 MLP[64,64] 与既有 PPO 学生一致；仅 BC（不试 DAgger/在线蒸馏——超出本实验
  的"兑现承诺"范围，列为后续）
- SAC 教师本身在随机采样下也会偶尔摔倒（8247 < 10000），其高方差（±711）是已知特性
- 未控制混淆：教师-学生容量差（[256,256] vs [64,64]）未排除——"免疫"与"容量不足"不可分；"高增益反馈"机制未直接测量（假说）

## 5. 对既有结论的限定

- README 蒸馏条目已限定："观测削减 92.6% 性能持平"只在 PPO 教师下成立（SAC 教师蒸馏阴性，见 §1）。
- 蒸馏对比口径：PPO 教师与学生同构（[64,64]），SAC 教师与学生异构（[256,256] vs [64,64]）——"SAC 免疫蒸馏"与"容量不足"不可分（见 §2.3）。
